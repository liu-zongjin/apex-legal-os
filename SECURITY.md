# Security policy

Please report suspected vulnerabilities privately to cuplsilence@foxmail.com.
Include the affected revision, a minimal reproduction using fictional data, and
the expected impact. Do not attach real client documents, case databases,
credentials, browser storage or other confidential material.

Reports involving local API authorization, filesystem access, document processing,
browser integrations, credential handling and update verification are especially
useful. The maintainer will assess reports as capacity permits; no response-time
guarantee or bug bounty is offered by this policy.

Do not publish exploit details in a public issue before coordinated review, and
do not test against systems or user data without authorization. The maintainer's
current development revision is the initial review target. Historical binaries retain the terms supplied with those downloads.
