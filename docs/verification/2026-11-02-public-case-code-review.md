# 公开类案检索代码审查与合并验证

范围：本轮公开互联网案例检索功能及其前端入口、网络适配、候选重排和证据核验。合并分支从 GitHub 当前隐私清理后的 main（1e71fc1）建立，不合并本地旧历史，不带入联系表、案件导入、源码客户端或管理后台等其他任务的未提交修改。不构建或发布安装包。

## 发现并修复

1. 未知 proof_kind 可能作为已证实事实进入支持结果。现仅接受已定义的证明类型，未知值降级。
2. 判决结果可以绕过实质说理要求。裁判方向引文现在只接受法院理由；处分结果用于辅助确认。
3. 摘录选择可能拼接不相邻句子，原校验只检查拼接后的摘录。现保留连续法院事实和理由，按原文校验引文；只忽略排版空白，不允许省略中间语句。连续来源仅在本地校验使用，不额外加入模型提示。结果缓存版本升至 7，避免复用旧的事实摘录。
4. 分批模型返回可引用未发送给该批次的索引。现按批次允许索引验收；畸形路径 ID 不再使整批核验异常。
5. 同案号正文被替换后可能继承旧核验。复用身份现包含来源链接及法院事实、理由文本；补全的续问与原始问题均交给核验及反证复核。
6. 零向量相似度误被当作缺值，落后于负相似度。修正排序，BM25 同时避免逐查询项反复计算文档长度。
7. 模型权重有固定哈希，词表原先只校验行数/特殊标记。安装与加载现在分别核对权重及词表的固定 SHA256。
8. 无效或空来源选择原先可静默回退专业 MCP。现拒绝无效选择；默认公开来源的普通分支也不再意外调用法随检索。
9. 新来源菜单移除了既有的“直接问 AI”和“直接问 AI · 联网搜索”入口。已恢复，保留公开案例与其他范围并存。
10. 前端版本更新必须覆盖全部离线消费者。同步入口、功能脚本、样式、离线工作线程和案件页面的对应引用，重建生成资产；不清理用户存储。

所有修复按通用数据结构、来源边界及证明逻辑实施，未按测试案号或法律领域添加生产规则。
