# 本地知识混合检索升级验收（2026-11-02）

## 范围与实现

知识库文章搜索、知识中心查知识共用 `backend/knowledge_search.py`。两个页面显式传入新增的 `semantic=true`；旧 API 调用默认行为保持不变。知识库原“模糊”开关改称“智能”，关闭后为文字包含搜索。案号、具体法条定位和明确引号查询保持文字查找；作者、标签、笔记范围不扩大到文章正文。目录、领域、标签、来源类型过滤在独立召回之前生效。

后台为完整文章正文分窗（220字、步长180），分别索引标题、摘要；知识中心索引争点、规则结论、适用条件、例外及来源标题。关键词 FTS5/BM25 与本地 BGE 向量独立从符合范围的完整索引召回，再进行 RRF 合并。不同于上一轮公开网页候选重排，此处确实对已收录本地语料建立持久向量索引。

独立 BGE cross-encoder 对最多48个候选进行相关性复核及排序，降低高余弦分数但内容无关的结果。负分的纯语义候选被排除，文字命中仍可查到。复核失败或繁忙时只展示文字匹配，并说明回退。原始整句文字命中、置顶和显式搜索字段保持可预测。知识中心继续限定已审核、有核验依据、争点有效且在有效期间内的结论；案件或收藏加分不能独立引入无关卡片。

结果增加真实字段及原文片段；正文复用现有原文跳转，内容经转义后展示。知识卡保留条件、例外和来源，不再将搜索命中描述为“可直接使用”。相似度和相关性复核都不证明法律结论成立。

## 数据、资源和更新

业务 SQLite 无新表、无编号迁移、无业务记录清理。衍生 SQLite 索引位于平台缓存，按业务数据库路径及模型/索引版本隔离，可删除重建。本地缓存含私人资料，不得进入源码或发行包。后台源连接为只读，文档指纹复用未变内容，单文档原子替换，删除记录清除；返回前再次核对源指纹，拒绝旧版本。

启动进行一次有限扫描，优先处理短知识卡，再处理长文章。后续搜索触发的完整检查最多每分钟一次，正文重建及结论编辑/审核会标记脏状态；其他更新路径由下一次检查补齐，故索引属于最终一致。初建或更新期间文字搜索可继续使用，界面明确显示覆盖不足或回退状态。没有空闲轮询。

复用24MB量化 BGE embedding，新增约279MB量化 BGE reranker及17MB分词器；小型 native tokenizers 依赖安装在模型缓存的隔离目录，不更改系统 Python 包。模型固定公开版本并校验SHA256，通过显式安装脚本下载。查询不下载模型、不调用云端推理、不产生按次模型API费用。推理限制两个CPU线程、分数缓存256项、复核并发准入等待0.5秒；交叉编码模型空闲五分钟后卸载。文章搜索防抖700ms；离线浏览器仍为文字搜索并明确说明。

模型方法与分数边界参照 [BGE官方说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)：余弦分数不能直接当作匹配概率，因此宽松向量候选还要经过独立重排。[复核模型来源](https://huggingface.co/BAAI/bge-reranker-base)，[固定ONNX转换版本](https://huggingface.co/Xenova/bge-reranker-base/tree/280bcc27a84e0b898c251e06fddb25171bd9b101)。

## 验证证据与限制

- 专项测试覆盖纯语义召回、字段/领域范围、未审核/过期/无核验结论、精确查询、分页、修改/删除、持久复用、索引/模型失败回退、重排拒绝和输入边界。全部使用临时匿名数据库。
- 两个页面的隔离浏览器测试覆盖1440和1024宽度、明暗模式、片段转义、原文跳转、语义标识、空结果及回退状态；没有连接或修改用户业务数据库。截图位于 `/tmp/stella-knowledge-articles-*` 和 `/tmp/stella-knowledge-center-*`。
- `scripts/verify_knowledge_search.py` 是可重跑的八领域匿名合成实验。最终真实本地模型：关键词 Top1/Top3 均6/8；混合加复核均7/8。四个无关生活问题均返回空结果。仍有“没签书面合同、每日受管理”的劳动关系问题未召回；未植入法律主题词典或案号特例修正。
- 小样本仅说明检索通道及重排确实工作，不是总体法律检索准确率。未开展大规模真实问法盲测、同领域极相近反向结论准确率评估；结果仍需核对原文主体、条件、否定和时序。
- 日志：`/tmp/stella-knowledge-unit.log`、`/tmp/stella-knowledge-ui.log`、`/tmp/stella-knowledge-extended.log`；跨领域原始结果：`/tmp/stella-knowledge-cross-domain.json`。第一次全量检查期间继续修改源码，触发仓库源码新鲜度保护导致503；冻结代码后重新检查，以最后一份日志为准。
