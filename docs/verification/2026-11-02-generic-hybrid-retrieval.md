# 通用检索审计与混合候选选择

## 对“只有关键词匹配，没有语义检索、向量混合检索”的判断

| 层次 | 审计发现 | 本轮处理 |
|---|---|---|
| 本地知识问答自有召回 | `search_articles_for_qa`主要为分词、LIKE及词项加权；文章搜索另有FTS5/BM25。没有发现自有的全量神经向量索引 | 如实保留结论；本轮不改本地知识库数据、索引或来源边界 |
| 专业MCP入口 | 代码提供远端语义/向量检索适配，执行取决于来源配置 | 不把远端能力算作本机独立检索能力；公开模式不调用 |
| 公开互联网检索 | 已有模型查询改写、事实路径及语义判读，但外部搜索仍主要为文字检索 | 移除样本专题分支，所有公开入口使用通用规划 |
| 公开候选选择 | 此前没有预训练稠密向量通道，仍主要用词项匹配和来源分数缩小候选 | 新增BM25、本地BGE向量、RRF分数及两路候选保留，再做模型证明关系核验 |

因此该结论指出了自有召回层的真实短板，但将整个Stella概括成完全没有语义能力并不准确。模型改写、语义判读、向量召回、候选重排是不同能力，不能混称。

## 去除测试题特化

- 公开研究不再调用旧专题规划器；收房、继续履行、发包人权属等本轮曾加入的专题分支已移除。
- `public_case_planning`只保留用户原问题及明确的层级、地域等筛选条件。
- `research_paths`不再注入固定事实路径、行为词、结论或案例号码。每次由当前问题和模型返回的数据生成，规划失败时明确降级到保留原问题。
- 删除专题正则判断，以通用证据身份替代：实际行为、协议安排、法律拟制、一方主张、假设及未知。测试覆盖这些结构，不靠某个法律术语触发规则。
- 公共必要条件进入每条可选路径；合取命题不能拆成删除条件的“其他路径”。
- 独立反证复核比对完整原问题与逐字引文，检查上位集合不证明下位特定条件、可能不等于确定、时序不等于因果、主体/对象/范围差异等一般推理问题。未通过或未完成者不计直接支持。

## 向量实现与边界

本机已安装并启用本地BGE-small-zh-v1.5量化ONNX模型，约24.01MB；词表约0.11MB。模型SHA256固定校验；仅CPU运行、两线程、有限批次及512条向量内存缓存。复用已有ONNX Runtime与NumPy，不引入Torch或新的云端文本接收方。

参考：[BAAI模型说明及CLS pooling](https://huggingface.co/BAAI/bge-small-zh-v1.5)、[ONNX量化模型及SHA256](https://huggingface.co/Xenova/bge-small-zh-v1.5/blob/main/onnx/model_quantized.onnx)。显式安装脚本为`scripts/install_case_embedding_model.py`。查询和启动不自动下载；其他环境未安装、校验失败或推理不可用时返回`bm25_only`及原因，不伪称已使用向量。

BM25使用分词及通用字符二元组，降低中文分词边界差异；稠密向量计算预训练语义相似度。RRF记录融合分数，但有限候选池必须同时保留词项和向量的高排名项，避免任一路独占。相似度不决定支持或反对，最终仍须核验实际事实和法院理由。

这是真实的候选级混合选择，不是全网或维基文库全库向量索引。未进入候选集的文书不能被后续重排找回；本地知识问答也没有在本轮自动获得全库向量检索。此边界不得在UI或报告中夸大。

## 验证与局限

1. 85项相关测试通过；最终extended运行1337项测试通过，27项跳过。本地服务报告current、无需重启。
2. 用劳动、公司、知识产权、家事、行政、刑事六个领域的匿名合成材料检查候选机制。六项中融合第一名命中4项，两路保留前两项覆盖6项；这是极小规模的领域候选实验，不能当作法律准确率，也没有证明向量总比关键词好。失败项保留，不按领域调权重。
3. 实际本地模型离线运行，得到有限且归一化的真实向量；查询未调用Embedding云API。故不是将词频数组或模型文字打分冒称神经语义向量。
4. 以未用于上一轮商品房测试的劳动、公司法问题，实际调用模型服务并联网检索；两个问题均记录`bm25+dense_rrf`和`vector_available=true`，规划内容对应各自领域，没有注入住房模板。
5. 第一版劳动判读拟纳入3项。独立反证复核确认其中1项只证明“非主要责任”，不能证明用户指定的“次要责任”，降为相关；另两项保留。公司问题拟纳入5项，复核以具体期限事实不足、主体路径差异等理由降级2项，保留3项。这是同批真实引文的分阶段实测，不冒称独立大样本端到端准确率。
6. 新版共同条件规划单独以实际模型服务验证：股东期限未到、公司不能清偿、债权人提前出资请求同时保留在一条完整路径中，不再把删条件的辅助角度当作替代路径。
7. 没有用用户提供的两个商品房案号作为生产规则、模型训练数据或本轮跨领域成功标准；此前这两个案号的自动召回缺口没有在本轮被宣称已解决。
