# 案件管理提醒代码审查与修复

日期：2026-10-28。起点：`269f7e6`。分支：`codex/case-reminder-review-20261027`。
范围：案件管理的待办、开庭、保全、上诉/异议列表，以及离线筛选、手机呈现与页面缓存。

## 已修复

1. 日期过期被解释为“待处理”：改为“已过期记录 N 条”，附说明日期不代表完成状态。行内同样改称“已过期”；不推断完成状态，不删除历史记录。
2. 排序被分桶与折叠破坏：四类提醒统一按日期时间升序，无有效日期的置后；相同时间按 ID 稳定排列。历史记录保留原排序位置，仅控制可见性，展开后连续排序。表头注明排序方向。
3. 离线待办的期限筛选遗漏 remind_at，导致逾期、7日内和30日内列表为空：纳入提醒日期。
4. “逾期”与“隐藏已过期”可同时启用造成空表：显式选择过期筛选时关闭隐藏；启用隐藏时退出过期筛选，重新请求数据。
5. 期限按钮选中状态及隐藏开关显示未随数据刷新：同步按钮、辅助状态、提示与复选框，不重建搜索框，保留输入焦点。
6. 过期判断使用 UTC 日期再归零可能偏移到前一天：统一解析本地日期，以日历天计算差值，覆盖上海、洛杉矶、UTC 与15天折叠边界。
7. 隐藏后无记录缺少反馈：桌面表格与手机列表显示“暂无符合条件的记录”；展开按钮限定当前表格并更新 aria-expanded。

页面缓存升级至290，同步后端声明、主页面、案件页面与Service Worker资源引用。IndexedDB、离线操作队列、业务 API 与数据库结构未改变。
