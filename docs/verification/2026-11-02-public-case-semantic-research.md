# 类案语义研究整改及对照验收

本轮仅改本地共用源码，未发布安装包、未调用专业案例数据库MCP。参考的是可观察的研究流程及案例检索Skill的命题卡/事实路径方法，没有声称复现模型服务内部实现。用户的公开互联网限定优先于Skill的数据源建议。

## 核心问题与修改

- 原来把关键词共现当作争点匹配，还在语义分析前筛掉改写表达的原文。现在公开研究模式先取得更大范围的完整候选，再分批核对；其他MCP检索路径保留兼容行为。
- 原来只有一轮搜索。现在拆分最多四条事实路径，交错执行查询；首轮不足时按覆盖缺口补检，倒查实际原文中出现的案号，最多两轮并限制总预算。模型凭空生成的案号不能成为倒查线索。
- 原来“收楼”只围绕该术语检索。现在把术语与可观察行为联系起来，例如办理收房手续、接收房屋、继续要求交付等；法院预先约定的救济安排与事后作出的选择分别说明，不自行把用户命题限缩成唯一事实路径。
- 原来所有关键词必须出现在同一条裁判引文中。现在分别要求每项关键事实与法院裁判理由有原文引证；不同路径不要求同案同时满足。
- 原来可能把当事人诉称当成法院已查明事实。现在单独提取法院查明部分；没有该部分时只能从法院说理寻找实际认定，不用诉称冒充事实。
- 保留法院说理结尾与裁判主文，避免节选遗漏最终结论；候选分批分析，每批最多4件、最多2批同时调用，降低长上下文遗漏与输出截断。
- 加入“拒收/视为交付不等于实际收房”的反例检查。合同仅约定可以选择也不能自动视为已作出选择。
- 修复结果缓存未包含查询式/事实路径的bug：补检改写不再拿回首轮旧结果。
- 按案号检索增加正文编号倒查，输出时必须与目标案号规范化后完全一致，不能用号码相似或主题相近的其他案子替代。
- 增加通用HTML搜索路径；来源、案名、案号、法院和链接仍由程序输出。部分相关最多展示两件，其余进入排除记录。

## 真实验证

### 不提供案号的原问题盲测

输入“检索案例：买受人已收楼或选择继续履行后，再主张解除合同不予支持的案例”。实际模型服务 Flash完成计划、联网、两轮检索、正文读取及分批判读，约84.2秒完成。16件候选进入语义复核，最终显示3份支持方向文书、1份反向、2份部分相关；其中3份支持文书含同案一二审，不能计作3个独立案件。

该轮支持方向包括（2023）青0104民初2368号，以及同案的（2023）青0203民初1613号、（2023）青02民终963号。后两份涉及约定期限内不解除而视为选择继续履行，必须保留该条件，不得扩张成“任何收房或履行行为一律使解除权消灭”。反向候选（2023）云0103民初3693号，指出先前继续履行选择不能当然阻止以后基于合同目的落空行使法定解除权。

这些是公开存档及AI判读结果，生效情况尚未逐件独立核验；不能声称已穷尽或已达到模型服务同等准确率。

### 原文分析的小样本对照

对真实取得的完整文书分别进行事实/说理/主文复核：

- （2023）鲁1003民初1734号：法院说理记载已办收房手续、领取钥匙，此后以逾期交房请求解除不符合约定条件。
- （2022）闽02民终1690号：法院认定要求整改后再通知交房的行为表明继续履行，此后以相同逾期理由要求解除缺乏依据。

两份文书均通过分项事实引文与裁判理由的逐字核对。这是已定位原文后的分析验收，不冒充两件都由盲搜自然召回；第二件曾由原问题自然检索命中。

### 用户指定的两个对照案

（2020）津02民终5096号、（2025）京02民终13918号：截至本次记录，自动案号检索没有取得匹配原文，验收状态仍为未通过。没有用其他案号替代，也没有以已知答案硬编码生产查询。

独立互联网搜索可以发现天津案的公开裁判转载、北京案的律所解读，但尚未核对到这两件对应的维基文库原页；不能把解读文章冒充裁判全文或据此断言维基文库不存在这两案。该差距仍属于待解决的召回覆盖问题。
