# 公开类案召回与核验第二轮整改

## 实际故障定位

只读查看用户指出的那次问答检索记录及其公共检索缓存，未修改历史或业务记录。原查询多次堆叠期待结果，缺少交易法律关系；两个可选路径的词项却混作同一词袋。补检优先倒查了一条候选引用的无关程序案号。公开网页适配等待所有查询结束后才读取正文，慢请求会耗尽来源预算。独立反证复核只有模型挑出的短引文，不能发现前后文的限定。

## 通用修复

- 当前问题动态产生最具体法律关系锚点，所有路径查询均保留首个具体锚点；通用诉请词不能代替法律关系。不添加专题分支或固定案号。
- 每个查询完成即开始读取其正文，最多十二个外部页面，每查询最多三个；某个慢查询不阻塞其他查询的正文。每来源四十秒上限，超时返回已取得材料。总研究预算四分钟，剩余不足两分钟不启动新一轮。
- 每路最多读取十个公开文书，语义模式每轮保留十六个候选，两轮证据池最多二十四个；保留关键词与向量通道。事实摘录使用动态同义词组，避免长事实描述无法逐字匹配而漏掉后部事实。
- 独立复核按四案分批、最多两批同时运行，核对引文及连续相邻原文。区分申请/办理与实际完成，核对实际裁判依据，不能仅以事实和结果共现认定直接支持。记录超时、模型/JSON错误及有效结论缺失。
- 部分相关、事实相反和未核实候选留在排除/检索记录，不作为主要案例卡片。事实引文去重，只展示已认定项目。补检优先缺口查询，关联案号放在其后。缓存版本升至八，检索关系进入缓存身份。

## 实测及失败保留

均以临时匿名数据库运行真实 DeepSeek Flash 与公共网络适配；未使用专业法律数据库 MCP，不将结果写入用户对话。

第一次整改实验耗时约84秒，模型拟保留两件。人工检查发现其中（2023）粤06民终3473号只证明到场办理手续，且实际驳回理由是无根本违约。增加原文邻接上下文后，同批复核将其降级，保留（2022）桂0722民初1349号的继续履行规则。随后完整重跑曾因不同查询与小候选池返回零件，保留该失败，未把增加筛选当成召回成功。

扩大有界候选池及修正锚点后，同题最新完整实测约94秒，返回（2022）川19民终877号一件支持案例；人工核对完整法院理由，涉及买受人实际接收并使用房屋、接收时承诺、之后主张解除，法院结合承诺、行使期限和法定解除条件不支持解除。本次只覆盖已收楼路径，继续履行路径仍存在召回缺口；不把原文中的附加条件省略成无条件规则。

跨领域完整实测：劳动通勤交通事故次要责任问题约28秒，返回（2023）陕71行终1623号，原文明确交警认定次要责任并维持工伤认定；公司不能清偿、未届期股东提前出资问题约31秒，返回（2024）苏03民终2421号等两件，原文含相应事实及裁判理由。已人工抽看法院完整理由；小样本不构成通用准确率或稳定性证明。劳动实验在候选池扩大前完成，公司实验在扩大后完成。没有用用户给出的两个商品房案号作为生产规则或强制命中标准。
