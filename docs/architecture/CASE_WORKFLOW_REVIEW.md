# 事实核对与证据册：实现与审查记录

日期：2026-10-14。恢复基线：16f1aac39ec55468a70b0d8126ec391a3cd88b90。

## 实现

案件详情和右键菜单进入工作台，复用案件选择器与本地文件浏览器。
事实核对支持粘贴文字或案件内草稿文件、所选材料、AI逐条初核、可验证逐字引句、
页/段/工作表定位、律师复核及 Word/Excel/Markdown/JSON 成果版本。
证据册支持证据标题、证明目的、顺序确认、PDF/图片/Word编册、页码和书签、
Word/Excel目录以及固定原件SHA256的页码映射。原件和案件状态均不改动。

任务元数据及成果落入绑定案件文件夹的 Stella办案成果/<任务ID>，原子保存；
无需数据库迁移。运行时采用单进程持久任务记录和一条重型办理队列，
不是支持多个服务器worker的分布式调度器。

## 差异与代码审查

本次逐段人工代码审查并用针对性测试、真实浏览器及渲染验证，不声称独立第三方审计。
审查覆盖新增服务、接口、任务恢复、文件路径、共享PDF装配、iframe协议、宿主导航、
页面状态与原有归档消费者；未变更原案件/客户数据源和既有AI问答协议。

发现并修复：

- Python 3.8不支持asyncio.to_thread；改用仓库既有线程适配，并延后初始化队列信号量。
- 混合PDF可能被整份平均文本量误判；事实核对逐页检查，未识别页不静默跳过。
- 旋转/裁剪PDF的可见方向可能改变；归一化时保持源页视觉方向，八种角度/裁剪组合做像素对比。
- 模型可能引用不存在的句子；仅接受候选片段中确实存在的引句，无有效引句不能标初核支持。
- 并行或同名输出覆盖；任务ID与版本目录独立，历史版本可下载。
- 材料更换后引用、恢复或复核出件可能沿用旧内容；原件hash与当前案件绑定复查。
- 用户输入能覆盖证据源hash等元数据；证据条目仅接受路径、标题和证明目的字段。
- Excel空列/公式缓存丢失语义；xlsx读取保留单元格坐标及公式/缓存状态。
- 未完成任务可以提前编辑复核；办理期间复核控件禁用。
- 未保存意见被切案或切任务丢弃；要求先保存，轮询不覆盖正在编辑的复核意见。
- 暗色子面板不随父页面变化、下载链接对比不足；同步主题并提高对比。
- 停止后台线程时清理与写入竞争；线程仅写独立暂存区，停止后不发布并由写入者清理。
- 立即停止尚未开始的任务可能传播CancelledError；取消入口捕获并持久化停止状态。
- 隐藏页面持续轮询；主工作区与嵌入材料浏览器均暂停后台刷新。
- 超过材料限额时前端可能静默截断；拒绝超量加入并提示，服务端也校验。
- 任务时间显示UTC日期；界面统一按Asia/Shanghai显示。

## 验证及实际限制

最终检查：APEX extended通过，778项回归测试通过；新增14项后端测试，
并完成匿名浏览器交互、1440/1024明暗截图、PDF可见页像素对比和Word目录渲染检查。

- 后端测试使用临时SQLite及匿名文件；原件字节不变、跨案拒绝、路径越界/符号链接拒绝、
  伪造引句、缺失主张、版本冲突、资料变更、转换失败、停止继续与重启状态均验证。
- 真实浏览器使用独立匿名服务器；实际操作材料选择、主张核对、人工复核、版本下载、
  原文查看、证据重排和PDF/Office导出；覆盖1440×900与1024×768明暗外观。
- PDF编册按可见页映射，目录独立不算入PDF；Word转换页数以实际转换结果为准。
- 模型语义是否正确、检索召回是否充分、材料证据效力仍需律师审阅。
  匿名UI预览使用明确标注的模型夹具，没有测试真实供应商AI或OCR准确率。
- 最多40份材料、80条草稿句子、24万字正文、1500页证据册、100MB单文件。
  超限不静默截断。候选检索不等于对全部材料的穷尽语义判断。
- 旧版xls须另存xlsx；含未确认Word修订须先核对修订并另存清洁稿。
- PDF/扫描件有未读页时先补充清晰材料，云OCR必须显式授权。
- Word编册沿用既有LibreOffice转换器，环境没有组件时可见失败，不发布部分成果。
- 构造编号的PDF是编册副本，不保留原PDF电子签名效力；原件仍完整保留。
- 未在真实客户卷宗、AppKit/WKWebView或远程多用户生产环境执行端到端验收。
