# 案由目录与选择器

目录由用户汇编《人民法院民事行政刑事案件案由汇编_2026-11-22 (1).md》生成。JSON 中保留汇编文件名、基准日、SHA-256、原始行号和来源链接。目录标记为汇编。分类与完整祖先名称共同生成稳定 ID。同一路径重新排序或更换原文行号时，ID 保持一致。更名或移动节点形成新路径，旧案件保存的名称仍可读取。

- 民事四级分别为 12、59、514、470 项。其中 514 条三级及其 470 条四级已逐项对照发布目录，顺序和名称一致。括号解析保留名称内部的顿号和嵌套括号。[最高人民法院发布目录](https://www.court.gov.cn/zixun/xiangqing/484231.html)
- 行政收录 1 个一级、22 个二级和 140 个三级。140 条编号条目已对照发布目录，编号及名称一致。占位符、未列举行为和专门案由仍按实际行为及适用规范核对。[行政案件案由的暂行规定](https://www.court.gov.cn/fabu/xiangqing/282681.html)
- 刑事收录 10 章、17 节和 483 项罪名。章节可展开，只有具体罪名可选。逐条对应刑法条文和历史罪名变更有待另行复核。[罪名补充规定（七）](https://www.court.gov.cn/fabu/xiangqing/288171.html) · [罪名补充规定（八）](https://www.court.gov.cn/fabu/xiangqing/424452.html)
- 汇编另有司法赔偿来源提示，该独立体系未纳入本目录。

目录可用 `python3 scripts/build_cause_catalog.py <汇编路径> --civil-html <最高法院民事发布页本地快照>` 重建，并生成民事三级、四级差异记录。省略快照时生成的核对状态为待核。

案件、文书和立案各自继续保存名称字段。新选条目的 ID 用于路径和浏览器内最近及常用记录。已有值按原文字回显，唯一匹配时定位目录，同名旧值由用户通过所属路径确认。原页面允许的自定义案由沿用原保存机制。立案候选保持官网来源和原匹配过程，汇编数据不会写入官网案由字典。
