# 移动端离线返回主页验证 · 2026-10-07

## 修复

旧手机桌面入口直接进入独立案件壳，缺少主界面的底部悬浮导航。应用壳 v231 在登录会话内准备主页及必要资源，旧入口接入已有主界面标签容器，沿用 `.tab-bar`、`goToMainView()` 和底部悬浮样式。内嵌案件页面不跳转。

资源齐全时才发布主页完成标记；登录页或不完整资源不会被当作主页。断网时读取已验证缓存，联网时仍服从登录响应。保留案件 IndexedDB、文章快照、目录偏好和待同步操作。

## 实测

- Chrome 390 × 844、真实 Service Worker、独立匿名 HTTP 夹具，无生产数据库。
- 联网安装并等待页面控制与主页完成标记；浏览器切换断网。
- 打开旧案件入口，进入主界面中的案件标签，内嵌案件页没有循环跳转。
- 原底部悬浮导航位置 x=10、y=778、宽370、高58；原主页按钮可以返回主界面。
- 断网刷新后仍可显示导航并返回主页；未抛未捕获异常。
- 故障回归覆盖离线带参数主页、在线登录优先、拒绝缓存登录页、资源下载失败、旧版本回退、iframe 保留原壳。
- 扩展检查：595 项测试通过，API 契约752条无变化。

## 操作边界

未使用实体 iPhone 测试。手机需联网打开一次最新入口并登录，让新版主页缓存准备完成，再退出重开桌面入口。此前从未缓存的文章或其他独立功能页面仍受各自离线能力限制。
