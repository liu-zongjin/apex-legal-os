# 移动端效率中心全屏布局（2026-10-16）

## 行为

移动端效率中心复用原有工具注册表、分类、排序及副标题设置，打开时覆盖整个可用视口。固定标题、编辑与关闭操作，下方固定案件、文书、AI、工具、邮件的分组定位；工具卡片按双列排布，只有列表区域滚动。编辑时使用单列，避免副标题输入框被挤压。

手机宽度至 768px 使用全屏；至 1024px 的粗指针触控设备横屏也采用全屏。桌面仍为锚定菜单，并限制菜单宽度避免左侧越界。全屏使用实色背景，避免底层内容透出。标题、长工具名和说明换行；安全区及 visualViewport 高度/偏移随键盘和方向变化更新。

全屏打开时暂时隔离背景交互，支持 Esc 关闭和 Tab 焦点循环。关闭或切换到桌面布局时恢复原有 inert 状态；菜单关闭后回到原锚点。选择入口复用原有跳转，不产生第二套工具或偏好数据。

## 验证

- Chrome、WebKit：320、390、430、768、1024、1440px，明暗主题；320px 短屏高度 568px。
- WebKit 粗指针触控：包含横屏与 1024px 平板场景。
- 分组定位与末尾入口可达、卡片/编辑框无横向溢出、固定页头、编辑取消、反复开关、背景恢复和真实案件入口跳转。
- 打开期间改变宽高及切换移动/桌面布局，检查全屏边界；桌面悬停关闭计时与视口几何验证分开。
- 原离线启动回归通过，文章/案件/待同步记录保持原存储契约。APEX extended 909 项检查通过。
- 通过真实前端和虚构数据的独立本地服务器验证，未访问实际案件数据库或外部业务服务。尚未在实体 iPhone/iPad 的软键盘、安全区和安装模式下验收。
