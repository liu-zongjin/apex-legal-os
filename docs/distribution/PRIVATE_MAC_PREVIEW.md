# 私密 Mac 体验包

使用 `python3 scripts/build_private_preview.py --output outputs/<new-directory>`
在 Apple 芯片 Mac 上构建独立的 `Stella Preview.app` 和 ZIP。构建依赖
PyInstaller、python-docx、项目运行依赖及 Xcode 命令行工具。

包内包含原生外壳、独立 Python 后端和程序资源，接收者无需安装 Python。
只从 Git HEAD 的 backend/frontend 程序文件和明确允许的品牌资源读取内容；
不复制工作区数据库、上传、用户模板、个人财务、日志、截图、浏览器配置、
密钥配置、原用户 Skills 或 Git 历史。归档模板从空白文档重新生成。
团队通用的硬编码律师资料按用户授权保留，接收者可自行设置 AI API、MCP 和 Skills。

体验版数据写入接收者的 `~/Library/Application Support/StellaPreview`，
监听本机 18865 端口，不沿用原应用的 8000 服务、数据库或 Skills 目录。
初次启动生成两个虚构案件和少量示例联系人/日程；个人财务及记忆为空。
单独的幂等标记添加三篇原创操作示例文章，不扫描或复制原知识库；
删除示例后再次启动不会将其恢复。新增示例没有法条引用或真实案情。
干净安装的默认首页使用程序自带 Stella 字标，避免浅色主题回退旧 C 图标。

仅配置的静态默认服务地址可能保留；所有用户 API/MCP 密钥和账号会话均不打包。
配置文件路径在构建快照中适配到独立数据目录，保持签名的应用目录只读。
构建完成前执行临时目录内的启动自检和文件审计，另生成 SHA-256 校验。

应用使用本地 ad-hoc 签名，没有开发者证书和 Apple 公证，不能声称是已公证发行版。
接收者可按 Apple 的“系统设置 → 隐私与安全性 → 仍要打开”流程选择信任来源：
https://support.apple.com/zh-cn/102445 。部分浏览器自动化与本地验证码识别是可选组件，
未将开发者的浏览器环境或下载的大模型随包复制。

安装包供授权团队成员内部体验，不公开发布、不改变原 GitHub 仓库权限。
这次用户选择自行上传，因此不调用网盘上传或创建分享链接。

## 验证范围

- 源文件白名单、即使被跟踪的私人文件排除、第三方公开证书/库资源区分。
- 原环境密钥清除、独立数据库和配置路径、示例幂等与删除后不恢复。
- 冻结应用在干净临时目录的真实 HTTP 页面与服务端自检。
- 默认首页与文章列表视觉检查，深浅色和两种桌面尺寸。
- 独立配置保存/清除测试使用无效匿名占位值，不发起真实外部 AI/MCP 请求。
