# 出处标签和定位审查

根因：共享 `_located_chunks` 在没有显式页码或工作表标记时，以3500字块为单位却标注“第N段”。此编号是检索片段序号，不是原件段号。DOC解析文本较短时全文只形成一个块，所有引句因此显示“第1段”。

修正：新检索块明确写为“提取文本片段N（未取得原件页码或段落位置）”，本地索引缓存版本升级为v2，按需重建。Word办理材料先检查修订，再优先复用既有转换组件生成PDF；逐页提取后标为“转换后PDF第N页”。转换不可用时返回原文本解析，并明确无可靠定位，不猜测页段。

已有任务不重写固定解析底稿或原件。展示与新导出将历史块段号标为定位未取得，保留逐字引句供查找。旧Word页码无转换依据时同样不认证。已发布历史文件保持原样。

原文依据使用中文“引文／材料”及来源文件清单。Word、Excel、Markdown、SVG、PDF和工作台对历史引用使用同样的定位表述；原件预览采用任务范围内的页面图像并保留原件下载。

匿名测试覆盖分片不是原件段落、实际两页Word转换、转换不可用回退、历史段号清理、两个事件复用引句及原文保存。真实用户文件仅用于本机排版验证，未发送模型或加入仓库。无法由旧导出恢复原件页码；旧任务需重新读取原件创建任务才能获取新的转换页码。
