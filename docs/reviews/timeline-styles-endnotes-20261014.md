# 时间轴样式与尾注审查

范围：时间轴导出设置、只读预览、Word原生尾注与三类布局。现有案件、引用验证、任务恢复与历史成果保持兼容。

- 设置严格接受axis/table/cards和布尔include_evidence，错误参数返回422，版本冲突返回409。保存时继续核验原件与绑定，失败清理新版本暂存文件。
- 三类布局有不同的信息组织方式；Word/PDF/SVG应用布局，Excel保持事实表。预览以当前已保存版本为依据，最多8项，原件变化或跨案请求拒绝访问，不调用模型。
- Word使用endnotes.xml、正确的包关系和内容类型、decimal编号及docEnd位置。首次引用创建真实endnoteReference，重复引用用bookmark和NOTEREF字段。渲染中发现默认罗马数字与复用数字不一致，已统一十进制编号并校正段属性顺序。
- 隐藏依据时不创建endnotes部件、不显示正文引用标记、不生成来源表/末尾原文。核验JSON保留全部原始事件、排除状态、复核意见及依据，UI明确提示这一边界。
- 交付正文不含复核状态或排除项。不可靠页段信息不作为正式定位输出，工作台和审计保留限制与原始字段，未补写页码。
- 内容转义覆盖SVG和PDF的全部事实及引句，预览作为图片显示并带no-store和限制性CSP；原有私有访问边界仍适用。
- 测试覆盖3种样式乘2种依据选项、真正尾注包结构、重复引用、排除记录保留在审计、长事件和长主体PDF完整性、SVG转义、参数与跨案边界、预览过期及原件变化、样式保存和浏览器刷新恢复。
- 用户提供的17项事实仅用于本地三个样式的逐页排版验证，未修改事实、未发送模型、未加入Git。Word源文件和生成PDF逐页检查。匿名浏览器验证三项既有办理流程，以及样式切换、依据开关、实际预览、六种成果下载。

限制：页面预览是SVG布局，Word采用可编辑原生结构、PDF采用分页布局，字体和分页可能有差异；预览基于保存版本，未保存复核修改需先生成新版才能同步。未验证真实AI准确率。
