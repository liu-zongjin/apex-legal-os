# 案件事实时间轴审查与验证

范围：案件办案工作台第三项“案件时间轴”，材料驱动，参考法律文书可选。没有数据库迁移。

## 数据闭环

- 使用本案件的固定材料快照和哈希校验解析底稿，逐片段分批提取，检查点支持继续办理。
- 事件必须有同批材料的逐字引句；日、月、年、期间和相对日期保持原件精度。内部排序边界不表示精确发生日期。
- 相同事项日期差异和重复记录仅为人工核对候选。语义支持和事件遗漏不能由引句存在性证明。
- 确认、人工修改、排除和手工补录保存为新版本；修改及排除须填写意见。补录只接受固定解析底稿中的原文。
- 保存前后均核验原件与案件绑定；版本冲突及导出中原件变化不会发布新成果。原始提取和历史版本保留。
- Word、Excel、Markdown、JSON、SVG及PDF保留日期、经过、复核状态和来源。排除项保留在底稿表格，不绘入时间轴。图形间距不表示时长。

## 审查中修复

- PDF生成复用已安装的PyMuPDF，消除当前Python3.8与外部PDF库不兼容导致的95%进度失败。
- 同一引句记载不同动作时保留独立事件；无有效引句的模型输出计入未采用数量。
- 未添加的补录内容不会被普通保存清空；保存期间冻结编辑，避免异步刷新丢失输入。
- 修复模式切换后旧证据编排区误显示；时间轴完成后收起输入区，聚焦事件复核。
- 同步主应用、案件入口、离线缓存资源版本，保持既有标签类型和跨页消息兼容。
- Word缩小标题并调整行距，短段落避免跨页断开；SVG长日期换行，PDF长正文自动分页。

## 验证

- 全量extended检查809项通过，812条公开API契约无意外变化。
- 时间轴及原有事实核对、证据册共32项任务测试，覆盖相对日期、无效日期、伪引句、同引句多动作、跨案访问、人工修订、手工补录、乐观版本、原件变更、导出中原件变更、参考文书对照及检查点恢复。
- 匿名浏览器实测完整原有流程及时间轴提取、原件预览、日期修订、补录输入保护、保存版本、刷新恢复和六种成果下载；1440/1024及明暗模式截图检查。
- Word经过渲染检查，PDF与SVG经过可视检查。所有测试使用临时数据库与匿名材料，模型使用固定测试应答，没有调用真实案件或真实供应商。

限制：批次上限40项、任务最多300项、1至40份材料、解析文本最多24万字，超过任务边界明确拒绝。逐片段处理不等于事件召回率保证；模型可能遗漏或误解，OCR及真实模型准确率尚未经案件评测。年月/范围日期可能重叠，排序不证明严格先后关系。
