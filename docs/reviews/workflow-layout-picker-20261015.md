# 工作台布局与材料用途审查

## 修复

- 菜单宽度大于其右对齐容器，产生负横坐标；工具栏 backdrop-filter 同时成为定位包含块。改为 body 层固定浮层，以窗口宽高夹取位置；空间不足时向上或滚动显示。
- 原菜单缺少键盘导航；增加首项聚焦、方向键、Home/End、Escape、Tab 退出及按钮焦点恢复。排除菜单焦点下文件列表空格预览快捷键，确保空格正常选择用途。
- 时间轴沿用证据编排的用途标签；按三个办理事项分别说明文件作用、典型材料与数量。说明是可选字段，归档类别消息保持兼容。
- 案件输入与事项切换按底部对齐；说明卡改为短提示；材料与办理表单统一等宽、上边界、间距与标题节奏。

## 验证范围

匿名临时数据库与材料，使用测试模型。浏览器检查 1440×900、1024×768 明暗外观的卡片和控件对齐、菜单四边界、矮 iframe、菜单键盘操作、用途随事项切换、单份文书限制及多份材料选择，并复测核对、编排、时间轴、保存恢复与六种交付下载。共用菜单的归档用途另行验证无说明字段和原分配消息。

未调用真实案件、上传真实材料或验证实际模型准确率。完整自动检查包含既有案件文件、归档及工作流测试。

验证结果：817 项自动测试通过，813 条 API 契约保持一致；真实浏览器全部匿名工作流场景通过，无页面脚本异常。明暗截图与交付文件保存于本机 outputs/stella-layout-picker-final。
