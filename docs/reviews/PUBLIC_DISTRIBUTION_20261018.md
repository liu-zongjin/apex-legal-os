# Stella 公开分发与前端一致性复核（2026-10-18）

## 发布基准与范围

应用程序基于私有源码提交 `cc7749c` 构建，包含原主分支之后的发票完整性修复与模型接入更新。源码仓库继续保持私有；公开下载仓库只发布应用、说明、校验结果与许可证。

公开版唯一主动删除的业务模块是个人中心及其家庭财务同步。其他程序功能、原生外壳、样式和前端构建流水线与当前本机版本共用。用户数据、服务凭据、账号登录、用户 Skills、浏览器档案和用户模板不复制；首次生成虚构案例与文章。

## 已确认的问题与修复

| 问题 | 结果 |
| --- | --- |
| 旧公开包来自较早快照，并注入独立 preview-brand.css | 新包从当前提交生成；去掉改变品牌尺寸与侧栏布局的体验版覆盖 |
| 干净安装没有当前品牌，原生端可能发布空标识 | 导出经授权的当前图片像素作为默认品牌；首次渲染预置标识；首次同步先读取默认值 |
| 品牌设置写入签名程序的只读资源路径 | 写入该安装实例的独立运行目录 |
| 恢复默认可能回到旧 C 标识 | 恢复授权的默认品牌，并立即同步页面 |
| 旧包保留团队、客户默认资料及原始后端文件 | 构建时替换团队姓名、昵称、证件、手机、地址、银行及真实客户默认值；冻结后去除原始后端 Python 文件 |
| 旧公开 ZIP 中确有上述默认值 | 16 个文本文件匹配原私人默认值，含 65 个原始后端 Python 文件；旧发行版已改为草稿，匿名下载已撤回 |
| 旧精简包排除本机已有 OCR 依赖 | 新包包含 ddddocr / ONNX Runtime；冻结后真实加载 OCR 引擎 |
| 个人中心是作者私人财务模块 | 公开构建排除页面、后端模块、家庭财务同步注册、效率中心项目及对应设置；私有源程序保留 |
| 旧体验版缓存和默认资料可能被沿用 | 新版使用 com.stella.public.native 和 StellaPublic 独立数据目录 |

## 一致性验证

- Chromium、WebKit 下检查首页 1440×900、1024×768、390×844 的深浅色，以及案件管理、文书合集、AI、MCP、Skills、发票和数据恢复，共 26 个视图。

- 冻结后端使用全新临时目录自检；两件虚构案件、三篇演示文章、无用户财务/长期记忆/账号密钥。只审计临时测试库，未读取或改写私人业务数据库。
