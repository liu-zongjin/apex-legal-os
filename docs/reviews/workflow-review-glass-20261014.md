# 办案工作台第二轮审查

范围：文书事实核对、证据编排及证据册、案件时间轴。不改变数据库或既有路由。

审查发现及修复：

1. 事实复核与编排保存只在生成前核验原件，生成过程中原件改变仍可能登记新成果。现在保存前后验证原件哈希及文件夹绑定，失败清理暂存成果，不改变已保存版本。
2. 事实复核状态若为对象或数组，集合成员判断会抛服务异常。增加类型校验，返回可理解的422反馈。
3. 事实复核在异步请求中同步生成Office文件，阻塞事件循环。导出与任务读取移入后台线程，持锁保证版本一致；并发异步健康请求的匿名测试验证不会被导出阻塞。
4. 快速页数读取可能在提交的忙碌状态结束前算出禁用按钮，提交结束未重新计算。现在统一在退出忙碌状态时重算编册条件。
5. 成果被材料区、办理记录挤到页面下部。成果现在排在记录之前，首次打开完成任务收起输入区；手动重新展开不会被同一任务刷新反复关闭。

界面：仅导航、模式选择和覆盖层使用磨砂玻璃，长文本和法律表格保持实色阅读面。时间轴选中记录有轴点和淡强调面，完整内容在右侧编辑区保留。复测1440/1024明暗模式、横向溢出、原件预览、保存与刷新恢复、导出、证据合并拆分及选页边界。

验证使用临时数据库、匿名文件与固定模型应答；真实OCR和模型事件提取准确率未纳入评测。原始案件数据未用于测试。
