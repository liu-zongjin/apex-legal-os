# 案件关联知识 · 实现与验收

日期：2026-10-15。分支：`feat/case-knowledge-match`。
开发前恢复点：`7fd1ddd0b1153370a8bfa9c50f3a493b397bde2a`。

## 交付行为

- 办案工作台第四项“案件关联知识”，支持只选文书、只选证据、混合材料及只粘贴文书。
- 可选我方立场和关注问题；分批提炼附原文的研究问题，复用本地 FTS／关键词检索，最多120篇去重候选、40篇实质正文分析、20篇双向引句核验推荐，先显示10篇。
- 支持论证、风险提示、程序取证、背景参考分别说明；展示具体用途、适用边界、文章上下文与案件原文。
- 可打开现有知识库文章、主动加入案件研究、调整问题创建新任务、下载Word及内部JSON底稿。
- 原件快照、停止恢复、原件变化拦截与不可变成果沿用已有机制；文章正文指纹及分析片段固定，当前文章修改／删除有提示，历史依据保留。
- 不新增数据库迁移或外部搜索，不修改知识库原文，不自动写入案件研究。现有三个工作流保留。
- 同步主页面脚本与离线预缓存版本，保证文章打开消息的主窗口接收逻辑可更新。

## 验证边界

使用临时数据库、匿名案件和模拟AI响应；没有读取真实业务数据库、上传真实案件或调用真实模型。因此验证了执行、检索、引用检查、界面和文件交付，未对实际案件的语义召回与推荐质量作准确率承诺。关键词召回不是穷尽检索，逐字引句有效也不等于文章观点适用于本案。

## 影响与兼容

共享能力：办案成果交付、主窗口文章打开、离线主页资源。文章加入继续使用既有幂等案件研究接口。新增GET文章快照接口按案件／任务／候选文章归属及快照hash校验。主窗口只接受同源已登记工作台iframe的版本化消息。没有修改客户库、案件主表、原件、结案状态或其他业务数据。
