尚未配置
只需配置一次，Cookie 不要发到聊天中。
  1. 点击本卡片的“后台”，在官方网页端登录对应邮箱。
  2. 打开浏览器开发者工具 → Network，清除筛选后点开任意邮箱请求。
  3. 在 Headers → Request Headers 的 Cookie 行复制完整内容，粘贴到上方并保存。
保存后可点击“验证超大附件”；会话失效时重新粘贴即可。

设置后仅检索所选文件夹，未选择的文件夹不会参与问答。
