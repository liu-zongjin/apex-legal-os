配置操作指引

      
1. 准备 SCNet 密钥
登录超算互联网控制台，在「API Key 管理」创建或复制可调用 OCR 的密钥。核对服务权限、账户余额与 OCR 可用额度。请勿把密钥发送给他人。

      打开超算互联网官网 ↗
      
2. 选择密钥方式并保存
已有 SCNet 配置：选择「复用 SCNet 密钥」。如需更换共用密钥，点击「打开 AI API 管理」，找到 SCNet → 配置 → 输入新密钥 → 保存配置，再返回本页测试。共用密钥变更也会影响使用它的大模型服务。

      
希望单独配置 OCR：选择「使用 OCR 专用密钥」，粘贴密钥，点击「保存配置」。首次必须填写；以后留空表示保留已有专用密钥。切回复用方式会保留专用密钥，便于日后再次使用。

      
保存后，新的图片及扫描 PDF 识别请求立即使用新配置。已开始的识别请求继续使用原配置。若显示由环境变量管理，请在部署配置中修改对应值并重启服务。

      
部署环境变量说明
SCNET_OCR_KEY_MODE=shared 表示复用 SCNET_API_KEY；设置为 dedicated 时使用 SCNET_OCR_API_KEY。环境变量优先于本机保存的配置；专用密钥不会覆盖大模型的密钥。普通桌面使用者直接在本页配置即可。

      
3. 点击实际识别测试
点击「发送样例图并测试」，等待识别文字、耗时和测试时间。显示「OCR 识别正常」表示本次样例识别成功；「已配置」只表示有密钥。结果仅代表该次请求，重新保存配置后需再次测试。

      
4. 在案件材料中使用
选择图片或扫描 PDF，在需要识别的页面勾选「允许本次扫描件发送至已配置的云端 OCR 服务」，再开始处理。有可读文字层的 PDF 通常直接提取文字。该设置管理案件文件、办案工作台及知识库扫描 PDF 的共用云端 OCR，不改变各页面的上传授权。

      
一张图片通常发起一次请求；扫描 PDF 会逐页识别，多页会产生多次请求。已提取并缓存的文字不会因为更换密钥而自动重新识别。自动化立案等已有的本机 OCR，以及官网验证码 OCR，沿用各自设置。

      
常见错误与处理
    
        
  • 401：密钥无效或失效，重新核对并保存。
    • 
        
  • 402／433／434：分别检查余额、团队消费限额、免费额度及付费开关。
    • 
        
  • 422：请求参数被拒绝；保存当前配置后重试，持续失败时联系支持。
    • 
        
  • 429：请求过于频繁，稍后重试。
    • 
        
  • 435：平台 OCR 处理异常，稍后重试；持续失败时向 SCNet 客服提供测试结果中的请求编号。
    • 
        
  • 437／438／441：检查图片格式和文件大小；单次上传不超过 10 MB。
    • 
        
  • 超时或无法连接：检查网络后重试。大模型检测失败与 OCR 检测失败应分别判断。
    • 
      

      
费用与材料上传
实际是否收费及扣费金额，以你的 SCNet 账户权益、订单和账单为准。OCR 识别与后续模型分析分别计量，免费或优惠状态可能变化。上传授权仅允许识别，不代表免费。
