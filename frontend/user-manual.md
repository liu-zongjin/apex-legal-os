>
> 文档版本：2026 年 10 月 2 日　以当前 macOS 桌面版为准；Windows 版功能以实际安装包为准

## 第一章　系统概述

### 1.1　什么是 Stella

「Stella」是 APEX 法律操作系统当前的 macOS 应用名称。它面向律师、律师团队与法务人员，把**知识检索、AI 增强问答、案件与案卷、文书、利息计算、法院服务、邮件和扫描件**放在同一工作台中。部分旧页面和导出文书仍使用「APEX」名称，指的是同一系统。

系统以本机数据为默认工作底座：知识、笔记、案件台账与本地文件关联均在您的设备上维护；需要调用 AI、MCP 外部数据、飞书或邮箱时，会在相应功能中单独配置。它的目标是把零散材料沉淀为可检索、可核验、可复用的律师个人数字资产。

### 1.2　核心能力一览

| 序号 | 亮点 | 说明 |
|------|------|------|
| 1 | 本地优先 | 核心知识、笔记、案件台账和使用设置保存在本机，可自行备份与迁移 |
| 2 | 多来源收录 | 网页、附件、本地路径、空白文档、国家法规库和会议录音均可进入知识库 |
| 3 | AI 增强问答 | 可在全库、目录、标签、领域、作者、单篇文章或案件文件范围内提问，并保留问答历史 |
| 4 | 知识中心 | 将文章沉淀为「法律问题—规则结论—原文依据」，支持引用核验、人工审核与相似问题合并 |
| 5 | 案件全流程 | 案件、待办、开庭、保全、期限、费用、系列案件与本地案件文件在同一工作区管理 |
| 6 | 法院与案例 | 提供一张网、法院通讯录、法答网、案件研究与可选外部案例 / 法规检索服务 |
| 7 | 文书与计算 | 所函、授权委托书、法定代表人证明书、文书合集、业务审批表、快速报批及多段利息计算 |
| 8 | 情报与协作 | 探索、法律雷达、晨报、飞书收录与团队费用同步，帮助持续追踪专业领域动态 |
| 9 | 办公归集 | 邮箱、发票中心、打印机扫描盘、案卷归档和下载中心衔接案件材料 |
| 10 | 管理与备份 | 效率中心入口可重排和改副标题；设置可管理品牌、备份计划、存储与性能 |

### 1.3　适用人群

- **独立执业律师与合伙人**：案件管理、文书生成、利息计算的日常办案刚需
- **律师团队 / 律所**：系列案件、团队案件台账、统一知识库沉淀
- **实习律师与助理**：法律检索、案例研究、备忘录自动生成
- **公司法务与法律研究者**：法规追踪、法律晨报、企业情报尽调

### 1.4　界面总览

系统采用「顶部标签栏 + 左侧知识导航 + 主内容区 + AI 增强区」布局。顶部 Stella 标识可返回首页；案件管理、一张网、已打开文章、知识中心、效率中心和设置按类别归组，点各组可切换已打开页面。左侧组织知识和笔记；AI 增强区可在选定范围内连续提问。

![效率中心展开菜单：案件、文书、AI、工具与邮件入口](/static/manual-images/efficiency-menu.png?v=2026100201)

> **特色设计**
>
> ① 在「设置 → 外观与体验」可选择“跟随系统”、浅色或深色；②「效率中心」可调整类别、顺序与副标题；③ 页面以标签形式并行打开，完成任务后可返回原页面。

### 1.5　先记住三个入口

1. **添加知识**：位于知识库页面右上角或工作台卡片中，用于收录网页、文件、法规与录音。
2. **效率中心**：位于顶部，用于打开案件、文书、AI、计算、邮箱、发票、扫描件和法院服务。
3. **AI 增强**：可从效率中心、文章页或各分类旁的 AI 按钮进入；先确认检索范围，再输入问题。

## 第二章　快速开始

### 2.1　Mac 用户

1. **安装** —— 将 Stella 放在有读写权限的本机目录中，不要在压缩包内直接运行。
2. **启动** —— 双击「Stella」。首次被 macOS 拦截时，在「系统设置 → 隐私与安全性」中选择「仍要打开」后重新启动。
3. **第三步：进入工作台** —— 桌面端会打开内置工作区；如使用浏览器部署版，则按部署说明访问本机地址。

### 2.2　Windows 用户

1. **第一步：解压** —— 解压收到的 Windows 安装包或压缩包，确认程序目录可正常读写。
2. **第二步：运行** —— 双击「APEX.exe」运行（会弹出黑色命令窗口，属正常现象）。如遇 Windows Defender 拦截提示，点击「更多信息 → 仍要运行」。
3. **第三步：使用** —— 浏览器会打开本机服务地址；端口以该安装包的启动提示为准。当前 macOS 版默认使用 `http://localhost:8000`。

### 2.3　注意事项

| 事项 | 说明 |
|------|------|
| 数据保存位置 | 本机数据库 `legal_kb.db`、上传文件、案件绑定的外部文件夹以及本机私密配置并非同一个文件；迁移前逐项核对 |
| 桌面端退出 | 直接退出 Stella；如另行运行本机服务，请按部署方式停止服务 |
| 端口冲突 | 仅浏览器部署版可能出现；如提示端口被占用，请按部署文档处理 |
| 防火墙 | 只有需访问外部 AI、MCP、飞书或邮箱时才需网络；请仅允许您信任的网络访问 |
| 多台设备 | 各设备的数据默认独立；切勿在两台正在运行的设备之间直接覆盖数据库，应停止服务后按第十七章迁移 |

### 2.4　常见问题

**Q：双击没有反应？**
A：确保已完全解压 ZIP 文件，不要直接在压缩包内运行。

**Q：浏览器没有自动打开？**
A：macOS 当前版本可尝试 `http://localhost:8000`；其他部署请查看启动提示中的地址。

**Q：数据会丢失吗？**
A：核心数据保存在本机，但磁盘损坏、误删或不完整迁移仍会造成损失。按第十七章设置自动备份并定期检查备份文件。

**Q：需要联网才能使用吗？**
A：知识库的收录、检索、阅读、案件管理、文书生成全部可离线使用；仅 AI 问答、MCP 权威检索、飞书同步等在线功能需要网络。

## 第三章　知识库管理

### 3.1　添加知识（六种收录方式）

点击右上角或侧边栏底部的「添加知识」按钮，弹出收录面板，可选择六种来源：

| 方式 | 适用场景 | 操作要点 |
|------|----------|----------|
| 网页链接 | 法律网站、公众号文章、法院官网、学术平台等 | 粘贴链接，系统自动提取标题、正文与来源，一键「解析并收录」 |
| 上传文档 | 法规、案例、论文、办案资料（保留文档结构） | 支持拖拽上传，兼容 PDF（OCR）、Word、Excel、TXT 等格式 |
| 本地路径 | 读取本机文件内容入库 | 填写本机文件路径，系统读取后收录 |
| 空白文档 | 自行撰写新知识 | 输入标题后进入沉浸式正文编辑器，支持富文本排版 |
| 国家法规库 | 收录官方权威法律法规 | 在「国家法律法规数据库」中检索，命中后直接收录，并自动检测效力状态与版本更新 |
| 会议录音 | 会议、培训、庭审旁听等场景转写入库 | 打开录音工作台，实时录音或上传音频自动转文字，AI 生成纪要后一键保存到知识库 |

**推荐工作流：先收录，再整理，最后提问。** 网页或文件入库后，先补齐标题、来源、标签与专业领域；需要研究时再从文章、标签或目录进入 AI 增强。这样既能保留原始材料，也能让后续问答有清晰的检索范围。

> **★ 飞书离线收录（特色功能）**
>
> 在「网页链接」方式下可展开「飞书离线收录设置」：配置飞书多维表格后，即使电脑关机，您也可以随时用手机通过飞书表单提交文章链接；系统下次启动后会自动解析并收录，并回写「同步状态、本地文章编号、同步时间」等字段。

### 3.2　知识组织：三级自定义体系

知识库提供「自定义库 → 标签组 / 标签 → 文章」组织架构，并配有独立的「专业领域」与「作者」分类体系。点知识库顶部的「标签与分类管理」，在「全部自定义库 / 专业领域 / 作者」三个页面集中调整名称、顺序或删除；保存前先检查影响的文章范围。

- **自定义库**：一级目录，可新建 / 重命名 / 删除 / 拖拽排序，如「公司法」「建设工程」等业务目录
- **标签组**：二级标签，可跨目录拖拽、将文章卡片直接拖入标签组；重命名时自动同步所有文章的标签
- **专业领域**：系统内置 18+ 法律领域（合同、刑事、强制执行、房地产、破产、担保合同、刑民交叉等），AI 按正文关键词自动分类，并支持人工修正
- **作者**：按文章作者聚合，方便追踪同一作者的观点与文章
- **AI 增强**：每个分类、标签、领域旁均有「AI」按钮，可基于该分类下的全部文章进行问答

### 3.3　全文检索

从「全部知识」顶部搜索框输入关键词，再选择检索范围；列表中可切换密度、打开文章及进入原文命中位置。

- 支持按「全部 / 标题 / 摘要 / 正文 / 标签 / 笔记 / 作者」限定范围检索
- 默认开启模糊搜索；命中正文时展示前后文片段，点击直达原文位置并高亮标注（标签命中为橙色高亮）
- 检索采用 BM25 相关性排序（标题权重 8 倍、摘要 4 倍），标题 / 标签 / 领域加权，结果更精准

### 3.4　阅读、笔记与编辑

- **沉浸式阅读**：全屏模式下左侧浮动摘要、右侧固定笔记栏、标题栏自动隐现，正文空间最大化
- **批注笔记**：选中正文任意文字即可快速添加笔记，笔记可搜索、可跳回原文位置
- **富文本编辑**：正文编辑器支持加粗 / 斜体 / 下划线、字号、颜色、标题级别、格式刷与行距调整，阅读与编辑样式完全一致
- **文章操作**：置顶、星标、批量标记「待读 / 已整理」、批量添加标签、批量导出清单，列表密度三档可调
- **目录与撤销**：智能目录保留各章下重复出现的小标题；Mac 输入框支持 `⌘Z` 撤销和 `⌘⇧Z` 重做。

### 3.5　今日推荐与最近阅读

系统每日从知识库中挑选 3 条值得打开的内容（综合权威来源、关注领域相关性、近期未利用度、笔记延伸度等评分），并记录您的「已读 / 跳过 / 不感兴趣」反馈以持续优化推荐；「最近阅读」自动记录最近打开过的文章，支持一键继续阅读或更新为「待读 / 已整理」。

### 3.6　可视化统计

「可视化统计」页面以图表呈现知识库全景：来源分布饼图、领域玫瑰图、30 天阅读热力图、月度柱状图、作者 Top10、领域词云等，点击图表可直接跳回主库筛选。

## 第四章　AI 智能问答

### 4.1　按资料范围提问

| 模式 | 检索范围 | 典型用法 |
|------|----------|----------|
| 全库问答 | 全部知识库 + 可选外部 MCP 来源 | 「建设工程优先受偿权的构成要件有哪些？」—— 回答自动引用库内文章 |
| 基于标签问答 | 指定标签组下全部文章 | 「基于标签『执行异议』下的文章回答……」 |
| 基于目录问答 | 自定义库二级目录下全部文章 | 在目录下直接发起问答，自动限定范围 |
| 单篇文章问答 | 仅当前文章 | 阅读页内点「AI」，仅基于该文章标题、摘要、正文回答 |
| 专业领域问答 | 指定专业领域下的文章 | 在「专业领域」分组旁点击 AI 按钮 |
| 作者问答 | 指定作者的全部文章 | 在「作者」分组旁点击 AI 按钮 |
| 案件文件问答 | 指定案件文件夹中的文件 | 在 AI 增强选择「案件文件」并勾选材料 |

**提问前的范围检查**：涉及具体案件时，优先选择相关文章、标签或案件文件。「MCP 扩展」中的「仅本地」只限制检索来源；若使用在线 AI 模型，问题和提供给模型的材料仍可能发送给模型服务商。需要查找外部权威资料时，再启用相应 MCP 服务。

### 4.2　高质量回答与可核验引用

- **引用规范**：AI 回答中的每一处关键结论均标注「（来源：《标题》）」，点击引用卡片可跳转到文章中对应段落并高亮显示，支持逐条核验
- **引用纠错**：系统会自动核对 AI 引用的文章 ID，对 AI 写错的引用进行反查修正
- **推理过程展示**：使用 DeepSeek-R1、豆包 Pro 等推理模型时，回答前展示可折叠的「思考过程」，支持全屏查看
- **智能降级**：模型限流（429 / 402）时自动切换备用模型继续回答，无感知中断
- **对话历史**：全库 / 文章 / 标签 / 目录的问答历史分区保存，可随时导出
- **任务可取消**：长问答可随时中断，进度实时推送
- **企业对比**：涉及多家企业的工商问题，可逐家检索登记、变更和任职资料；判断交叉任职前核对各企业是否实际返回相应字段，不把缺失字段当作否定结论。

### 4.3　模型与密钥管理

在「设置 → AI API 管理」页面可管理已接入的服务商与模型：配置密钥、测试连接、查看可用性、设置默认模型或隐藏不常用模型。当前默认工作流可使用 DeepSeek V4.1 Flash；模型会随配置变化，以当前界面为准。密钥保存在本机私有配置中。

> **保密提示**
>
> 发送给第三方 AI 或外部 MCP 的内容，可能会离开本机。涉及尚未公开的案情、身份信息或证据材料时，请先脱敏，或使用仅本地检索模式。

## 第五章　知识中心与关系图谱

### 5.1　知识中心：先用知识，再做治理

进入「知识中心」后先从「今日」搜索或打开推荐结论；审核队列在右上角「知识治理」内。

![知识中心的今日页：搜索、当前工作相关知识和间隔复习](/static/manual-images/knowledge-center-current.png?v=2026100201)

「知识中心」是日常查找、学习和调用法律知识的入口。打开后默认进入「今日」，从居中的搜索框开始；这里会显示当前案件相关知识、最近使用和收藏。旧的 `/legal-knowledge` 地址与文章中的 `claim_id` 深链接继续有效。

- **查知识**：只展示已通过、在有效期间且存在核验依据的结论卡；当前案件只调整已命中内容的排序，搜索页可查看或清除案件上下文。结果显示真实总数，并可继续加载。卡片可查看规则、适用条件、例外限制、效力信息和权威来源；详情可查看原文、复制带核验依据的结论、加入案件研究或带入 AI 提问。
- **检索历史**：「今日」和「查知识」各可保存最近 10 条成功检索；可点击回填、单条删除或清空。完全重复的结论在日常列表中折叠展示。
- **渐进式筛选**：专业领域和主题分类收进搜索页的轻量筛选条，首次使用无需先理解完整分类体系。
- **5 分钟复习**：每天最多 8 张卡，可选择一个或多个领域。先主动回忆法律问题，再揭示结论与依据；反馈「忘了 / 模糊 / 掌握」决定后续复习时间，可收藏或暂停。
- **知识治理**：右上角次级入口只在需要时打开，承载需复核、可审核、相似问题建议和处理失败。审核区保留原文依据门槛、审计记录和危险操作确认，不影响日常检索。

知识结论一旦被退回、驳回、合并或因原文变化进入复核，会立即退出检索和复习队列。复习反馈与打开、查看来源、复制、加入案件等行为只记录必要的本地使用事件，不保存案情或搜索原文。

知识中心后台仍然保留以下治理能力：对知识库文章逐段调用 AI 提取「法律问题 — 规则结论 — 原文依据」三元组，将零散文章沉淀为结构化的个人法律问题库。

- **自动提取**：一键对单篇或全部文章发起提取任务，按内容哈希去重，支持强制重跑
- **引文核验**：每条结论引用的原文必须逐字命中文章段落，未通过核验的结论自动丢弃，杜绝 AI 编造
- **人工审核**：提取结果进入审核队列，支持通过 / 拒绝 / 合并三种状态；置信度 100% 且引文核验通过的自动放行
- **问题归类**：AI 自动将法律问题归类到领域目录树（置信度 + 来源双重标记），支持人工修正
- **相似合并建议**：AI 检测相似问题并生成合并建议，逐条审阅后可一键合并，避免问题库重复膨胀

### 5.2　关系图谱：文章之间的法律脉络

系统自动识别文章中的法条（如《民法典》第 578 条，中英文数字条号归一化）、案件与法律问题，构建「节点 — 提及」关系网络：

- **节点库**：法律问题、法条、案件三类节点，配别名体系（如「民诉法」→「民事诉讼法」）
- **关系扫描**：扫描文章段落生成节点与文章之间的引用关系，按上下文推断「依据 / 补充 / 冲突」等关系类型
- **阅读联动**：文章阅读页点击「关系」按钮，即可查看该文引用的法条与案件、以及讨论同一问题的其他文章
- **成本可控**：扫描前显示预估成本，可手动 / 自动扫描，AI 扫描需授权确认

## 第六章　案件管理

「案件管理」是办案工作台，覆盖案件信息、待办事项、开庭提醒、财产保全、上诉 / 异议期、司法短信、导入中心、案件日历等工作区，并可与「一张网」同步的官网案件信息联动。整个模块支持离线快照缓存，断网也可查看已缓存的案件数据。

### 6.1　案件台账

在「效率中心 → 案件管理」进入案件信息页，可搜索、筛选和打开普通案件或系列案件；顶部还可切换待办、开庭、保全、期限、司法短信与案件日历。

![案件管理的案件清单与工作区入口；图中案件为演示数据](/static/manual-images/case-manager-current.png?v=2026100201)

- **完整案件档案**：案件类型、当前阶段、案号（一审 / 二审 / 执行等）、法院与当事人联系方式、委托人与对方当事人库

- **批量操作**：批量归档、批量删除、置顶、按 11 个字段（标题 / 当事人 / 案号 / 案由 / 阶段等）搜索
- **审计留痕**：每次变更写入审计日志，可追溯
- **AI 查找**：粘贴文字由 AI 自动识别出委托人 / 对方当事人信息并入库

**建议建立案件的顺序**：先新建案件并补齐案号、法院、当事人和阶段；再创建待办、开庭、保全或期限记录；最后绑定本地案件文件夹。这样提醒、研究、文书和扫描件归档都能落到同一案件上下文中。

### 6.2　开庭提醒：短信 / 图片智能识别

除手动新建开庭外，系统支持「开庭通知智能识别」：将法院发来的短信文本（或开庭通知的截图 / PDF）粘贴或上传，OCR + AI 自动解析出法院、开庭时间、地点、案号、联系人，并自动匹配到对应案件合并建档。

### 6.3　财产保全与上诉 / 异议期

- **财产保全**：保全类型（财产 / 证据保全等）、保全资产内容、起止日期、期限与到期提醒
- **上诉 / 异议期**：上诉、执行异议、复议等期限类型，自动计算截止日并提前提醒

### 6.4　司法短信自动解析（macOS 特色）

系统可直接读取 macOS「信息」应用中的法院短信数据库，由 AI 自动分类解析出案号、法院、开庭时间、经办机构等信息，一键生成待办、开庭、上诉期记录，并关联文书下载归档——办案信息从短信到台账全程自动化。

### 6.5　导入中心：Excel 批量建档

上传 .xlsx / .xls 表格，系统智能识别「案件 / 开庭 / 保全 / 上诉」四类表格结构，预览确认后批量导入，历史案件迁移一步到位。

### 6.6　案件日历：一键同步 Apple 日历

开庭、保全、上诉期记录可一键同步到 Apple 日历（macOS），各类型分别配置提前提醒天数（如开庭默认提前 30 / 15 / 10 / 5 天）与提醒时间（默认 09:00），支持多日历选择与取消同步。

### 6.7　系列案件

面向批量型案件：创建系列 → 导入首批子案 → 在子案信息主表维护自定义列和公共信息 → 将需要的列映射至各子案详情。主表支持多单元格复制；「详情」打开与普通案件一致的完整详情页。需要批量修改时，先导出 Excel，编辑后执行「导入更新」，逐行核对新增、修改、删除与不变项，再确认。导入前会保存可回退版本，系列内保留最近 10 个版本；Excel 缺失的编号行会先进入垃圾站，请在确认页特别检查。

### 6.8　团队费用管理（效率中心 → 案件）

- **收支记录**：每笔支出 / 垫付按时间序自动计算滚动余额，类别可管理、常用描述预设
- **飞书多维表格双向同步**：配置后本地记录自动写回飞书（自动创建 / 更新 / 关闭重复记录），也可从飞书拉取，支持案件项目选项同步
- **导出 Excel**：支出 / 垫付明细 + 余额一键导出

### 6.9　案件文件：本地文件夹工作区（macOS 特色）

每个案件可绑定一个本地文件夹，文件仍保留在原来的位置。系统提供 Finder 风格分栏浏览、多条件排序、搜索、预览、重命名、移动 / 复制 / 粘贴、删除到废纸篓等能力，并可选中文档发起 AI 问答。文件与文件夹会显示访达标签颜色；右键菜单可设置或移除颜色，选择文件夹时可递归应用到下级文件。请先确认选择范围再执行递归操作。

### 6.10　合同自动化生成

基于团队模板（如《民事委托代理合同》）一键生成合同：AI 解析模板定位待填字段 → 从案件自动带入当事人、案号、律师信息 → 金额大小写转换、费用条款按风险层级自动生成、特别授权范围勾选 → HTML 精确预览 + PDF 预览 → 导出 docx（封面、条款、动态页脚域）。费用方案预设与律师费条款生成器支持基础 + 奖励制等模式。

### 6.11　一张网：人民法院在线服务联动

### 6.13　案卷归档工作台

打开「效率中心 → 案件 → 案卷归档工作台」，选择已绑定本地文件夹的案件。系统按律所诉讼、非诉样本及刑事清单展示材料类别；系列案件优先显示子案正式名称。

2. 在本地核对当事人、案由、诉请、附件分类及需要在线生成的材料；识别内容只作为待核对草稿。
3. 确认后执行一张网官网草稿填报，并在「提交前确认」检查字段和上传位置。最终「提交立案申请」、验证码、身份核验和电子签名仍由律师本人完成。

### 7.1　研究项目

- **争点拆解**：复杂问题可拆分为多个检索方向，避免一次检索遗漏关键情形。

### 7.3　案件研究台账与备忘录

## 第九章　利息计算工具

### 9.1　多段利率智能计算

![计算工具：分段利率、计算明细与结果汇总](/static/manual-images/interest-calculator.jpg?v=2026083002)

- **按 LPR 变动自动分段**：每段独立配置起息日、止息日、利率方式，段头实时摘要（如「2025-01-01 ~ 2026-01-01 LPR×1.5+20BP」）
- **两种利率模式**：按 LPR 倍数（支持上浮 BP，实时换算「上浮 0.20%」）或按固定利率
- 按 360 天折算日利率（保留 5 位小数），天数含起止日，自动避免分段日期重叠
- 分段小计 + 利息 / 本息总计，金额一键复制（含大写金额转换）

### 9.2　AI 参数识别（特色功能）

把判决书原文或一段描述文字粘贴进来，工具优先用内置本地规则识别本金、多段起止日期、LPR 倍数、上浮 BP、固定利率等参数并回填表单（日期区间、金额「万元」换算、分数利率「年息 X 厘」等 20+ 规则）；只有文字中存在本地规则无法识别的计算内容时，才自动调用 AI 补充识别。

### 9.3　Excel 导出与历史记录

- 导出的 Excel 含真实公式（日利率 = 年利率 / 360、天数 = 止息日 - 起息日 + 1、利息 = 本金 × 日利率 × 天数），可继续二次加工
- 排版专业：标题行深红、表头深灰、公式列分色、冻结前 3 行、说明行标注计算方式
- LPR 历史数据可增删改、恢复默认；历史记录最多保留 50 条，可置顶、备注、按时间清理、点击回填重算

## 第十三章　外部数据服务（MCP 集成）

系统通过 MCP（Model Context Protocol）协议接入权威法律数据服务，让 AI 问答与案例检索不仅依赖本地知识库，还能实时调用外部专业数据。在「设置 → MCP 服务管理」页面可查看每个服务的地址、授权状态、工具列表与连接状态，支持一键握手测试（返回延迟毫秒）。

### 13.1　服务清单

| 服务 | 提供方 | 核心能力 |
|------|--------|----------|

> **★ 数据安全**

发票中心上方是邮箱、时间范围、文件类型和主题关键词筛选；点击「扫描发票」后，下方才显示结果表。

- **月度自动归集**：在「自动归集」中新建任务，设定每月执行日期、时间、邮箱、关键词和文件类型；系统扫描上一个自然月并在本机生成 ZIP 压缩包

3. 点击「归入案件」将文件取回到案件文件夹；也可下载到本机，或发送至 AI 增强进行材料问答。

> **OCR 提示**
>
> 图片型 PDF 发送至 AI 前可能需要 OCR。只有您勾选「允许必要时发送至 OCR 服务」后，系统才会在确有必要时进行识别。

## 附录　常见问题（FAQ）

**问：AI 问答没有反应或提示失败？**
答：请检查网络连接，并在「设置 → AI API 管理」中确认默认服务商的密钥已正确配置、测试连接通过；遇到模型限流时系统会自动切换备用模型。

**问：案例检索返回空？**
答：案例检索依赖法随 / 元典等 MCP 服务，请先在「MCP 服务管理」中确认相关服务状态为已连接；元典服务可能需要有效授权。

**问：飞书同步不生效？**
答：检查多维表格链接是否包含 /base/ 与 table= 参数、App ID / Secret 是否正确，并确认表格包含要求的全部字段；保存后点击「保存并验证」查看返回信息。

**问：如何把旧电脑数据搬到新电脑？**
答：先停止两端服务，按第十七章备份数据库、上传文件、外部案件文件夹和所需配置；迁移后抽查文章附件、案件路径及外部授权。

**问：Mac 上双击无法打开？**
答：先确认应用已完整解压；如 macOS 拦截，请在「系统设置 → 隐私与安全性」中按系统提示选择「仍要打开」。

**问：司法短信读取不到？**
答：该功能读取 macOS「信息」应用的数据，请确认「信息」应用已登录且短信存在，并在系统设置中允许 APEX 法律操作系统访问「信息」数据。
