# Stella 使用说明书

> 本说明按当前本地桌面版整理。功能入口可由用户调整；外部服务和不同平台的可用性以实际页面和配置为准。

## 1. 认识工作台

Stella 把知识库、案件管理、AI 增强和日常办案工具放在同一工作台。顶部可切换案件管理、一张网、已打开文章和效率中心；左侧组织知识，主区域显示当前页面。点击顶部 Stella 标识可返回首页。

「效率中心」提供案件、文书、AI、工具和邮件入口。入口可以调整分类、顺序和副标题，因此你的排列可能与本说明不同。设置窗口顶部的「使用说明书」可随时重新打开本页。

## 2. 开始使用

### 安装与启动

Mac 用户请先完整解压安装包，再打开 Stella。遇到 macOS 拦截时，可在系统设置的「隐私与安全性」中按提示操作。Windows 用户请按所下载版本的安装说明操作；完整离线包需要先解压，再运行包内的「开始安装.cmd」。升级前请备份重要资料。各版本安装要求请查看[官网下载指引](https://liu-zongjin.github.io/stella-downloads/download.html)。

知识和案件资料以本机为基础。已有资料的离线可用范围取决于缓存和本机组件；网页收录、在线 AI、法院同步、邮箱、MCP 和飞书等功能需要相应网络连接与配置。

### 配置服务

打开「设置 → 工作空间」：

- **AI API 管理**：配置服务和密钥、测试连接，设置模型及业务使用的模型。
- **OCR 配置与测试**：配置和测试文字识别服务。
- **邮箱配置**：管理 QQ 邮箱、腾讯企业邮箱和网易企业邮箱。
- **MCP 服务管理**：管理外部数据服务及其授权、测试连接。
- **Skill 管理**：查看本机已登记的 Skill 及其说明和文件。
- **离线缓存管理、储存管理**：查看缓存和空间使用情况。

外部服务使用自己的账号、密钥或授权。发送问题或文件前，请确认接收服务及材料内容。

## 3. 收录和查找知识

点击「添加知识」，可按页面选择网页链接、上传文档、本地路径、空白文档、国家法规库或会议录音。网页和法规检索需要网络；上传文件及本地路径支持的格式以对应面板提示为准。提交后检查标题、正文和来源，再按需整理分类。

国家法规库面板提供检索和「一键检测更新」；检测后请核对并选择要更新的项目。会议录音入口会打开录音工作台，可录音或上传音频，再按页面提示处理和保存。

在知识库搜索框输入关键词，可选择搜索范围。侧边栏的自定义库、标签、专业领域和作者帮助整理文章；标签与分类管理可调整分类。打开文章后可阅读、编辑和添加笔记；修改后请保存。页面中的 AI 入口可带入相应的文章或分类上下文。

### 文章表格和 Excel

普通文章编辑器提供表格操作。导入 Excel 后可在表格页面查看和编辑单元格；「保存修改」保存编辑副本，「导出已保存表格」导出保存后的结果。切换工作表或关闭前留意未保存提示。公式及旧格式的处理请以页面提示为准，重要文件建议保留原件并在导出后核对。

## 4. AI 增强与材料分析

打开「AI 增强」后，选择模型和问答方式，输入问题并发送。可以按需选择本地文件、案件文件或 Skill；使用文章、分类等入口打开时，先检查当前上下文。历史问答可从面板中查看和搜索。

「本次不记忆」控制本次记忆使用；「长期记忆」「上下文」「策略总览」可分别查看有关内容。具体可用的模型和外部来源取决于设置。联网模型可能接收问题与附带材料，即使检索范围仅限本地，也不意味着模型调用在本机完成。

面板顶部的「执行任务」会进入办案工作台的材料分析任务入口。选择材料并按提示交办后，可查看和复核任务结果。AI 的识别、摘要和引用都需要结合原文核对，不能代替事实或法律判断。

## 5. 案件管理

从顶部或「效率中心 → 案件管理」进入。案件管理提供案件台账、待办、开庭、保全、期限、司法短信和案件日历等入口。新建案件时按页面步骤填写客户、当事人、案由和名称；保存后可继续完善案号、法院、联系人、进展及关联文件。

待办既可单独创建，也可关联案件。开庭和期限记录保存前请核对日期、案号和提醒设置；日历提醒规则可按需调整。系列案件提供子案表格及 Excel 导入更新，导入时应先查看差异并确认。

可为案件绑定本地文件夹，以便浏览案件材料并从其他功能关联。绑定的是原有文件夹，迁移到另一台电脑后应重新检查路径是否可用。

### 智能立案与自动化立案

案件详情中的「智能立案」可围绕案件及所选材料准备立案草稿、提出待确认问题和辅助填写。另有「效率中心 → 案件 → 自动化立案」，可绑定立案材料文件夹，扫描并核对识别出的信息，再按页面提示执行官网草稿流程。

两者均应先检查当事人、案由、请求和附件分类。法院官网的身份核验、验证码、签名及最终提交须由本人完成。案由目录在「设置 → 工作空间 → 自动化立案」更新和查看。

### 司法短信与一张网

司法短信入口可辅助识别法院通知并生成待核对记录。Mac 的信息读取需要相应系统权限；其他平台以页面提供的导入方式为准。识别结果应在保存前核对。

「一张网」连接本人人民法院在线服务账户，登录后可同步和查看页面提供的待办、消息、电子送达等记录；可将适合的记录关联本地案件，并按页面提示预览或下载材料。登录状态、官网数据和可用功能取决于账户及法院服务。

### 案卷归档工作台

在「效率中心 → 案件 → 案卷归档工作台」选择案件，浏览已绑定文件夹中的材料，分类并核对清单。「保存归档清单」保存整理结果；生成电子案卷是另一步。新生成的归档材料位于案件文件夹下的「Stella案卷归档」。旧名称的归档目录仍会被识别为历史输出，避免重复收录。

### 办案工作台和案件研究

「办案工作台」围绕证据、事实、时间轴和关联知识整理材料；按页面选择文书与材料，审阅原文依据后再导出或继续编排。「案件研究」用于组织研究问题、关联资料和问答，外部案例、法规检索需要相应服务可用。

## 6. 知识中心、法答网与探索

知识中心提供查找知识、复习和治理入口。查看结论时可打开依据与来源；提取、审核、合并等操作应结合原文进行人工核对。关系图谱用于查看文章和相关法律信息之间的联系。

「法答网」提供精选答问的检索与阅读。使用时应核对原文、发布日期和法律依据。「探索」和法律雷达用于查找与跟踪信息，具体来源和推送能力取决于网络与配置。

## 7. 文书和计算

效率中心的「文书」提供所函、授权委托书、法定代表人的证明书、文书合集、业务审批表和快速报批等入口。选择对应工具，填写或带入资料，检查预览后导出。律所标识等可在外观设置中管理；正式使用前请核对当事人、授权范围和格式。

「计算工具」可用于利息及费用计算。填写本金、日期及利率等条件，检查分段和计算明细，再按页面提供的方式导出。AI 识别出的参数需要与原始文书逐项核对。

## 8. 邮箱、发票、扫描件和下载

配置邮箱后，可从效率中心打开对应邮箱查看邮件、处理附件和写信。发票中心可按邮箱、时间和条件扫描、筛选并归集票据；执行自动归集前需设置任务并确认账户连接。

打印机扫描盘用于连接已配置的局域网扫描信箱。连接后可查看扫描件，选择案件并按提示归档或下载。具体设备和凭据保存方式以页面提示为准。

下载中心汇总应用内的下载记录。打开记录可查看状态和保存位置；将材料存入案件前，请确认目标案件及已绑定的文件夹。清理记录前应阅读页面提示，确认其对实际文件的影响。

## 9. 设置

设置顶部搜索只查找设置页内的名称和说明，支持不连续字符匹配；选择结果后跳转至相关设置。搜索框旁可直接打开本说明书。

- **工作空间**：AI、OCR、邮箱、MCP、Skill、缓存、储存和自动化立案案由目录。
- **工作效率**：页面总览和快捷键。
- **外观与体验**：目录展开方式、主题配色、启动与动效、搜索偏好和品牌标识。
- **账户与安全**：登录会话和个人中心保护；可用选项以当前安装为准。
- **系统与支持**：性能诊断、智能页面休眠和说明书。诊断中的时间及内存数值用于辅助排查，统计范围以页面说明为准。
- **备份管理**：设置自动备份周期、时间和保留天数，查看及管理备份文件。

工作空间的案由目录默认收起明细，点击「查看已缓存的案由」展开；「更新官网案由目录」从官网获取目录供立案匹配，匹配结果仍需核对。

## 10. 备份与迁移

在「设置 → 备份管理」配置计划并检查备份记录。数据库、上传附件、案件绑定的外部文件夹、私密配置和钥匙串凭据并非同一份数据；迁移前请逐项备份。复制或恢复前应停止相关服务，迁移后检查附件、案件文件夹路径和外部服务授权。不要直接用一台正在运行的设备的数据覆盖另一台设备的数据作为同步方式。

## 11. 快捷键

默认快捷键可在「设置 → 工作效率 → 快捷键」查看和修改。下表是当前默认绑定；如果你已自定义，以设置页为准。Mac 上 Alt 对应 Option 键。

| 默认按键 | 功能 |
|---|---|
| Alt + 1 | 全部知识 |
| Alt + 2 | 添加知识 |
| Alt + 3 | AI 增强 |
| Alt + 4 | 案件管理 |
| Alt + 5 | 案件研究 |
| Alt + 6 | 知识中心 |
| Alt + 7 | 法答网 |
| Alt + 8 | 计算工具 |
| Alt + Q | 聚焦搜索 |
| Alt + O | 设置 |
| Alt + P | 效率中心 |

## 12. 遇到问题

- **AI 不响应或报错**：检查网络、模型配置和连接测试结果；核对当前问答范围及附件。
- **法院或邮箱未连接**：检查对应账户、授权与网络，并查看页面提示；验证码和重新登录可能需要本人操作。
- **找不到案件文件**：检查案件绑定的本地文件夹是否存在，以及当前设备是否有访问权限。
- **页面卡顿或占用较高**：在「设置 → 系统与支持」查看性能诊断；关闭不需要的页面，或按需启用智能页面休眠。
- **需要迁移资料**：先核对第 10 节列出的各类数据，完成备份后再迁移。
